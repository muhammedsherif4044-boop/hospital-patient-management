# Hospital-Patient-Management-System

A Hospital Patient Management System using Java, HTML, CSS and JavaScript.

The project uses a **Linked List** to store patient records dynamically (patient ID, name, age, gender, disease, phone number and doctor name). Staff can add, display, search, update and delete records, and keep a patient waiting queue.

## Files
- `HospitalPatientManagement.java` – console version (Linked List, Scanner, exception handling)
- `index.html`, `style.css`, `script.js` – web version of the same system

## Run
- Java: `javac HospitalPatientManagement.java` then `java HospitalPatientManagement`
- Web: open `index.html` in a browser
